# API reference

Every function in the Bolt API as of SDK 10, by header and by name. Each page
describes its functions under the names an application writes; built against the
SDK, each name calls the numbered export beside it, which never changes. See
[Compatibility](../guide/compatibility.md).

This page is made by `scripts/mksdk.py` from the headers. The pages it links to are
written by hand.

## By header

| Header | Library | What it covers | Functions |
|---|---|---|---|
| [user.h](user.md) | `user.lib` | handles, memory, time, input, files, sound, the version, services, the command line | 107 |
| [graphics.h](graphics.md) | `user.lib` | drawing | 13 |
| [registry.h](registry.md) | `user.lib` | the registry | 19 |
| [modres.h](modres.md) | `user.lib` | what a module carries; versions and the SDK record | 9 |
| [wndmgr.h](wndmgr.md) | `wndmgr.lib` | windows | 36 |
| [cmnctl2.h](cmnctl2.md) | `cmnctl2.lib` | the retained controls | 64 |
| [cmnctl.h](cmnctl.md) | `cmnctl.lib` | the immediate-mode controls | 21 |
| [shellapi.h](shellapi.md) | `boltshell.lib` | starting programs, message boxes, links | 30 |
| [psapi.h](psapi.md) | `psapi.lib` | processes | 13 |
| [netapi.h](netapi.md) | `netapi.lib` | connections | 11 |

And the pages that are not one header's:

- [Messages](messages.md) — what the system calls in an application, and the window messages
- [Types, errors and folders](types.md) — the base types, the error codes, where things live
- [The C library subset](crt.md) — `memcpy`, `sprintf` and the rest, and where they differ
