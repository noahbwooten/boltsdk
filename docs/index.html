Guides

Read in this order the first time.

  1. Setting up — Python, clang and lld, QEMU, on Windows, Debian and macOS.
  2. Getting started — build the calculator, run it, and make an application of your own from the empty one.
  3. How an application runs — modules, frames, the entry points, windows and messages, memory, and what an application may and may not do.
  4. The project file — every key in app.ini.
  5. Resources and versions — icons and sounds, the version manifest, boltapp.h.
  6. Packaging — .bxi installers, links and registry values.
  7. Running and debugging — the disk, run, slipstreaming, the serial log.
  8. Compatibility — BOLTSDK_APIV, numbered functions, and what never changes.
